# Stage 1-XL Consolidated Report

20× item expansion (197 → 3,997 measured items: 3,800 generated by qwen25-32b
+ 185 re-measured validation originals + 12 pinned anchors) with anchored
Thurstonian μ re-measurement on three subjects. Orchestration: parallel
3-agent item QC, live gate monitoring with auto-halt (never triggered),
QC sensitivity analysis at consolidation.

## Gates — anchored protocol validates on every subject

| model | gate (a): anchored-μ vs full-battery μ (n=185 originals) | verdict |
|---|---|---|
| qwen25-7b | r = +0.973, ρ = +0.972 | PASS |
| qwen3-4b | r = +0.933, ρ = +0.969 | PASS |
| llama31-8b | r = +0.953, ρ = +0.967 | PASS |

12 μ-spanning, frame-stable anchors × 48 letter-logit readouts per item
recover the full adaptive battery's utilities almost perfectly — the anchored
design is a validated cheap substitute (~190k readouts/model, ~1h each).

## The re-powered curvature question (the reason for the expansion)

Held-out r predicting μ, layer = per-model manifold layer, 2-fold cross-fit:

| model | ridge n=197 → n≈4k | spline n=197 → n≈4k | line control n≈4k |
|---|---|---|---|
| llama31-8b | 0.57 → **0.85** | 0.31 → 0.55 | 0.47 |
| qwen25-7b | 0.75 → **0.89** | 0.44 → 0.60 | 0.59 |
| qwen3-4b | 0.65 → **0.83** | 0.36 → 0.52 | 0.46 |

Verdict, sharpened not overturned: **the gap does not close.** Everything
improves with 20× data, but the supervised linear ridge improves more and
stays 0.25–0.33 ahead of the geometric pipeline. Two nuances the scale run
adds: (i) a small but consistent spline-over-line margin appears for llama
(+0.08) and qwen3-4b (+0.06) that did not exist at n=197 — detectable mild
curvature, economically irrelevant next to the ridge; (ii) qwen25-7b shows
none (spline ≈ line). "Utility is a linear direction, best read by supervised
regression" is now a properly-powered claim. Ridge directions saved per model
in `utility_dir.pt` → Stage 4C steering.

## Item QC (3 parallel agents over 3,800 generated items)

441 flagged (11.6%): 363 dup, 48 malformed, 28 wrong-domain, **2
valence-loaded** (exemplar-only band prompting kept wording neutral).
Worst domain: selfstates (21% — templated paraphrase families). Flags in
`items_xl/qc_flags.json`.

**Sensitivity check** (all analyses re-run excluding flagged items, n=3,544):
ridge 0.86/0.88/0.84, spline 0.55/0.61/0.51, line 0.43/0.59/0.44 — every
conclusion unchanged within noise (`qc_sensitivity.txt`). Recommendation:
use the QC-filtered set for Stage 4 pool selection; keep the full set for
measurement-methods reporting.

## Confound audit at scale

Generated-item μ regressed on surface covariates: r² = 0.07–0.15 (vs 0.23 on
the original 197), largest loading surface_sentiment 0.21–0.27, freq/monetary
≈ 0. The expanded measurements are, if anything, less world-statistics-
confounded than the originals.
